# Elevator v1 Phase 1 fixture foundation

The executable, namespace-scoped fixture builder is
`tests/fixtures/elevator.py`. It represents four synthetic residents, six elevator
incidents, unrelated private messages, clean and forwarded photo metadata, a contradiction,
private unit/family-health details, malicious prompt-injection evidence, and a missed
commitment.

This Phase 1 foundation intentionally does **not** contain precomputed agent conclusions,
shareable views, proposals, approvals, sends, schedules, or watcher results. The complete
24-message ambient input corpus and its adapter are Phase 3 work.
